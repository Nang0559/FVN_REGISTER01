> Mục tiêu: ghi nhận cách làm hiện tại và so sánh sau khi áp dụng. Không điền số giả định vào cột kết quả thực tế.

## 2. Phiếu đo thời gian cho một giao dịch

Ghi số phút lao động thực tế của từng vai trò. Không cộng thời gian chờ nếu người đó không trực tiếp làm việc trong khoảng chờ.

| Công đoạn | Vai trò | Trước (phút) | Sau (phút) | Cách ghi nhận / nguồn |
|---|---|---:|---:|---|
| Chuẩn bị và gửi yêu cầu | Nhân viên |  |  | Quan sát / ghi nhận |
| Kiểm tra thông tin | Nhân viên / bộ phận phụ trách |  |  | Quan sát / ghi nhận |
| Phê duyệt | Người phê duyệt |  |  | Nhật ký / quan sát |
| Nhắc việc và tìm hồ sơ | Bộ phận liên quan |  |  | Nhật ký / quan sát |
| Đối chiếu và xử lý ngoại lệ | HR / bộ phận phụ trách |  |  | Nhật ký / quan sát |
| Tổng hợp báo cáo | Người lập báo cáo |  |  | Thời gian thực tế |

**Giờ công giải phóng** = số giao dịch × (tổng phút lao động trước − tổng phút lao động sau) / 60.

## 3. Bảng KPI trước–sau

| Chỉ số | Định nghĩa thống nhất | Trước | Sau | Chênh lệch | Nguồn dữ liệu / người xác nhận |
|---|---|---:|---:|---:|---|
| Số giao dịch | Tổng giao dịch thuộc phạm vi trong kỳ |  |  |  |  |
| Phút xử lý/giao dịch | Tổng phút lao động / số giao dịch |  |  |  |  |
| Lượt thao tác thủ công/giao dịch | Số lượt chuyển, nhập lại, nhắc, tìm, đối chiếu / số giao dịch |  |  |  |  |
| Thời gian chờ phê duyệt | Gửi yêu cầu đến quyết định; ghi rõ dùng trung vị hay trung bình |  |  |  |  |
| Tỷ lệ làm lại | Hồ sơ cần sửa hoặc xử lý lại / tổng hồ sơ |  |  |  |  |
| Tỷ lệ đúng hạn | Công việc hoàn tất đúng hạn / công việc đến hạn |  |  |  |  |
| Giờ lập báo cáo | Tổng giờ lao động thực tế trong kỳ |  |  |  |  |
| Thời gian truy xuất | Thời gian tìm hồ sơ/bằng chứng theo mẫu kiểm tra |  |  |  |  |
| Tỷ lệ sử dụng hệ thống | Giao dịch trên hệ thống / tổng giao dịch trong phạm vi |  |  |  |  |

## 4. Tính lợi ích — chỉ sau khi xác nhận dữ liệu

1. **Giờ công/tháng** = số giao dịch × (phút lao động trước − phút lao động sau) / 60.
2. **Giá trị năng lực quy đổi** = giờ công giải phóng × chi phí lao động quy đổi/giờ đã được thống nhất.
3. **Chi phí giấy tờ giảm** = chi phí thực tế trước − chi phí thực tế sau.
4. **Chi phí làm lại giảm** = chi phí làm lại trước − chi phí làm lại sau.

Tránh tính trùng thời gian làm lại trong cả giờ công và chi phí làm lại. Giờ công giải phóng không mặc nhiên là tiết kiệm tiền mặt.

## 5. Xác nhận kết quả

- [ ] Cùng định nghĩa KPI trước và sau.
- [ ] Cùng phạm vi nghiệp vụ hoặc đã giải thích khác biệt.
- [ ] Đã ghi số lượng giao dịch và biến động khối lượng.
- [ ] Đã ghi nguồn dữ liệu và người xác nhận.
- [ ] Đã tính chi phí triển khai, đào tạo, vận hành và duy trì.
- [ ] Đã tách lợi ích đo được khỏi lợi ích định tính.
- [ ] Đã được bộ phận nghiệp vụ và người phụ trách số liệu xác nhận.
